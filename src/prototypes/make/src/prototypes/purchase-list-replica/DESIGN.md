# 智能体 Axure 原型复刻设计基底

## 来源

- 原型链接：https://axhub.im/ax11/e5ef191e5eea4a38/?id=5ldspe&p=%E9%87%87%E8%B4%AD%E6%B8%85%E5%8D%95&g=1
- 源文件：用户提供的 `智能体.zip` Axure HTML 导出包。
- 视觉基底：导出包本身，不新增主题方向。

## 复刻范围

- 页面树、页面资源和原始样式均直接使用导出包；Make 入口允许在其上增加本轮确认的交互预览层。
- 页面共 8 个：语音菜单、语音生成菜单、查看菜单、智能排产、订货采购、采购清单、确认下单、下单成功。
- Make 入口加载 `axure/start_with_pages.html`，保留 Axure 原始播放器和页面树。

## 实现边界

- 不直接修改导出包中的页面、文案、视觉样式或交互。
- 原型代码负责加载导出包，并在 Make React 入口中承载本轮智能排产对话预览；导出包内的 HTML、CSS、JavaScript、图片和资源完整放在 `axure/` 下。
