客户驾驶舱需求 · 原型主规格

本文档是用户与 Agent 围绕「客户驾驶舱需求」原型进行方案沟通、确认和持续生成的事实依据。需求来源为《客户驾驶舱需求 PRD》（V0.1，需求评审稿）。

当前方案

  • 原型意图：面向客户领导与参观人员的无人智厨展示大屏，通过设备协同示意、烹饪流程、设备能力与行为监控，帮助接待人员讲清无人厨房的组成与价值。
  • 使用场景：大屏（非触摸）持续展示；接待／讲解人员用 iPad 控制端切换展示主题，不执行任何生产操作。
  • 当前表达：深蓝 + 青色大屏视觉，横屏 16:9 基准；两个展示页（运营驾驶舱、行为监控）+ 一个 iPad 控制页 + 一个保留优化的生产驾驶舱旧页；全部数据为演示数据并显式标注。

事实与输入

用户确认事实

  • 大屏页面：运营驾驶舱、行为监控；默认首页为运营驾驶舱。（2026-09-23 按需求暂时下线：厨房总览、无人烹饪流程、核心设备与能力，页面实现保留可恢复。）
  • 厨房总览采用「设备协同示意图」，不依赖真实三维模型，不冒充现场还原。
  • 五类候选设备与器具：炒菜机、机械臂、烤箱、容器、层架；容器与层架按器具展示，不默认计为联网设备。
  • 行为监控五类异常：未佩戴口罩、未佩戴帽子、发现老鼠、发现抽烟、发现人员；「发现人员」计入全部异常。
  • 非触摸大屏适配；iPad 仅控制展示，不提供设备操作入口。
  • 本次改造只在「客户驾驶舱需求」副本内进行，不改动原「单独展示版」及其他原型。
  • 本次实现范围：大屏展示页 + iPad 控制页；原有生产驾驶舱保留并优化为独立页面，保留生产进度、投料、烹饪和出餐结构；营养健康与食品安全入口不纳入客户展示范围。（2026-09-23 起展示页由五页缩减为运营驾驶舱、行为监控两页。）
  • 用户已移除能源消耗、无人厨房现场、独立设备运行状态和物料运维提醒模块。当前运营驾驶舱聚合生产任务、烹饪区设备标注、用料／出成；不纳入食安、营养和就餐服务模块。

当前假设

  • 大屏按横屏 16:9 设计，最小宽度 1180px；最终分辨率、物理尺寸与观看距离待确认。
  • 原型内用 localStorage + 自定义事件模拟 iPad 与大屏的跨端联动；同浏览器模拟不构成跨设备联动验收。
  • 客户／项目名称、品牌素材未确认，页面以「待确认」占位，不沿用参考页的「江南校区」。
  • 行为监控数值为自洽的演示数据（全部异常 = 五类之和），不代表真实去重口径。
  • 烹饪流程环节为结构示例，具体菜品与生产流程待业务方补充。

原型范围

本次呈现

  • 运营驾驶舱（默认首页）：顶部提供「运营驾驶舱」「行为监控」两个大按钮，生产任务、烹饪区设备标注、用料／出成总览；底部不展示页面导航。
  • 暂时下线（2026-09-23 按需求暂停展示）：厨房总览、无人烹饪流程、核心设备与能力。页面实现仍保留在 pages/ 下，恢复时取消路由、导航与 import 中的注释即可。
  • 已下线页面的既有约定仍然有效，恢复后照此呈现：厨房总览为设备协同示意图、节点职责与假设关系标注；无人烹饪流程中炒菜机与烤箱按并行加工路径呈现、人工环节如实保留；核心设备与能力含五类候选设备与器具，型号与数量缺省为「—」。
  • 行为监控：五类异常分类统计、抓拍卡片网格（时间倒序）、缺图缺失态、演示数据标识。
  • iPad 展示控制页：目标大屏名称、连接状态、展示页直达（当前为运营驾驶舱、行为监控）、当前页反馈、返回首页、切换中与切换失败状态、监控周期筛选（仅行为监控控制区）、演示开关。
  • 原有「生产驾驶舱」内容保留并优化，通过 #page=cockpit 或页面切换器进入；生产任务统计明确为演示数据。

本次不呈现

  • 厨房设备启停、配方修改、任务下发、生产调度、异常处置与工单操作。
  • 食安台账、晨检、留样、农残检测、营养健康等独立模块。
  • 真实厨房三维建模或数字孪生状态同步。
  • 未确认可获取的称重、任务进度、运行状态、人工介入及节省人工等真实量化指标接入；运营驾驶舱只保留明确标注的演示值。
  • 多场地、多大屏集群管理；原生 iPad App。
  • 监控视频直播与录像回放（本期以抓拍事件为基准）。

评审用深链

行为监控的数据状态可用 URL 参数直接打开，便于逐一核对异常分支（仅读不写，不影响 iPad 控制端状态）：

  • #page=behavior&monitor=ready：正常展示
  • #page=behavior&monitor=loading：数据加载中
  • #page=behavior&monitor=empty：所选时段无事件
  • #page=behavior&monitor=failed：获取失败（保留缓存）
  • #page=behavior&monitor=offline：监控未接入

跨窗口联动：同一浏览器另开一个窗口打开大屏页，在 iPad 控制页切页或切换周期即可看到大屏跟随。此为原型模拟，不构成跨设备联动验收。

iPad 控制页的「演示开关」可模拟控制连接中断、切换失败，以及行为监控的五种数据状态；正式交付不含该区域。
