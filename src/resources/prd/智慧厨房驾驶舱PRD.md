# 客户驾驶舱需求 PRD

版本：V1.2｜日期：2026-10-14｜状态：开发需求稿

## 1. 产品定义

### 1.1 一句话定位

智慧厨房驾驶舱是面向后厨管理者、客户领导和参观讲解人员的 Web 大屏系统，用统一的菜品任务、生产流程、出餐记录和营养数据，呈现厨房从投料到出餐的完整过程。

### 1.2 产品形态

- 形态：桌面 Web 大屏。
- 目标尺寸：1920 × 1080，横屏 16:9。

## 2. 用户与使用场景

| 用户     | 核心任务                       |
| ------ | -------------------------- |
| 后厨管理者  | 查看当前餐段任务、完成量、生产重量、设备和出餐进度  |
| 客户领导   | 快速理解厨房生产能力、流程组织和今日供餐情况     |
| 参观讲解人员 | 按页面顺序讲解生产烹饪、营养健康、出餐统计和行为监控 |

### 2.1 典型场景

1. 进入“生产烹饪”，先查看当前餐段、生产流程和今日菜单。
2. 查看生产进度列表，定位烹饪中的菜品及其已烹饪时间、总时长和温度。
3. 进入“营养健康”，从今日菜单选择餐品，查看营养分析和餐品图片。
4. 进入“出餐统计”，按餐段查看菜品计划、完成情况和任务明细。
5. 进入“行为监控”，查看行为分类、事件数量和图片记录。

## 3. 产品范围

### 3.1 本期范围（P0）

- 顶部导航、系统时间和页面状态。
- 生产烹饪：生产流程、今日菜单、餐品统计图、今日出餐、生产进度、明厨亮灶、出餐记录。
- 营养健康：膳食结构建议、营养分析、营养分析列表、今日菜单和 餐品图片。
- 出餐统计：餐段筛选、计划与完成汇总、菜品统计、任务明细。
- 行为监控：沿用现有页面展示，本期不新增行为监控需求或字段。
- 驾驶舱配置后台：维护驾驶舱基本信息、显示页面、页面/模块显示名称及页面专属设置；配置结果同步至大屏示意。
- 生产工艺查看/编辑：默认进入营养素页签；营养素支持手动维护和 AI 生成覆盖，并提供 AI 超时、无原料等异常状态页面。
- 统一菜品数据、重量数据、烹饪时间和设备温度字段。

## 7. 功能详细需求

### 7.1 全局导航与时间

| 项目   | 需求                                                       |
| ---- | -------------------------------------------------------- |
| 页面标题 | 显示后台配置的智厨驾驶舱名称；未配置时使用默认名称                                |
| 导航   | 系统提供生产烹饪、营养健康、出餐统计、行为监控四页；根据后台“显示页面”多选决定实际显示项，顺序保持系统默认顺序 |
| 当前项  | 当前页面导航高亮；页面自定义名称仅改变大屏实际显示名，不改变后台系统页签名；路由切换后内容同步          |
| 页面轮播 | 后台统一设置开关与间隔；开启时仅在已选页面间循环，默认 20 秒，间隔可配置                   |
| 系统时间 | 右上角显示 `YYYY-MM-DD HH:mm:ss`，作为烹饪计时的统一时间基准                |
| 缩放   | 根据窗口尺寸缩放主画布，保持 16:9 比例，避免内容裁切                            |

遥控器实体按键，映射为标准键盘码。默认映射如下

| 业务动作      | 默认键盘 code    | 业务功能                                             |
| --------- | ------------ | ------------------------------------------------ |
| 播放 / 暂停轮播 | `Enter`      | 开关顶层页面自动轮播，与大屏页面轮播按钮共用状态。                        |
| 上一页面      | `ArrowLeft`  | 循环切换到上一个已显示页面。循环切换到上一个已启用页面；当前为第 1 页时，直接跳转至最后一页。 |
| 下一页面      | `ArrowRight` | 循环切换到下一个已显示页面。循环切换到下一个已启用页面；当前为最后一页时，直接跳转至第 1 页。 |

- 四个系统页面及其默认顺序固定；后台可多选实际显示页面，不提供页面排序。自动轮播、手动导航和逻辑按键只作用于已显示页面。
- 页面轮播默认开启、默认间隔 20 秒；后台可关闭轮播或调整间隔。运行中手动切页后重新计时，暂停时仍可手动切页且保持暂停。
- 页面导航、轮播按钮和遥控器映射共用当前页面与轮播状态，页面高亮及按钮文案同步更新。
- 遥控器为可选功能；关闭后不响应映射按键。
- 营养健康页内餐品图片/分析轮播独立配置和控制，不受顶层页面轮播或遥控器按键控制；

### 7.2 生产流程图

- 展示投料区、烹饪区、出餐区、入口、设备和出口。
- 入口按食堂实际配置的来
- 设备类型、设备名称、设备数量按食堂实际配置来
- 出口按食堂实际配置来
- 生产卡片沿对应路径移动，路径起点、终点和当前节点必须绑定同一条路线。
- 按照实际情况，卡片停留在对应区域。
- 动画要与节点状态，任务完成量、出餐记录或设备字段联动并且保持一致。
- 卡片颜色与菜品颜色保持一致

### 7.3 今日菜单与餐品统计图

- 展示今日菜单，按餐段分组。
- 今日菜品总数=排产的去重菜品数+临时加菜的去重菜品数
- 汇总展示：总产量（盆数和重量）、当前已完成（盆数和重量）、总产量重量（kg）、已完成重量（kg）、总进度条（已完成盆数/总产量）
- 统计图每行展示：餐品名称、重量进度条、已完成重量 / 总重量。
- 今日菜单内容：已经排产的去重菜品名称

计算规则：

- `总产量盆数 = Σ(已排产的菜品盆数+临时加菜的菜品盆数)`
- `总产量重量 = Σ(已排产的菜品总重量+临时加菜的菜品总重量)`
- `当前已完成盆数 = Σ(已排产中已经出餐的菜品盆数+临时加菜中已经出餐的菜品盆数）`
- `当前已完成重量 = Σ(已排产中已经出餐的菜品总重量+临时加菜中已经出餐的菜品总重量）`
- `总重量（单个菜品） = Σ(已排产的总重量+临时加菜的菜品总重量)`。
- `已完成重量（单个菜品） = Σ(已排产中已经出餐的总重量+临时加菜中已经出餐的总重量)`。
- `已完成重量 = Σ 餐品已完成重量`
- `结果保留 1 位小数。`

### 7.4 生产进度

每行显示：

- 菜品名称、状态、设备、生产重量、盆数、进度。
- 状态取工单状态。
- 生产重量，单位 kg。工单菜品的总重量
- 完成盆数 / 计划盆数。
- 进度条。
- 当状态为“烹饪中”时，追加已烹饪时间、总烹饪时长和设备温度。

烹饪计时规则：

- `已烹饪时间 = 当前时间 - 烹饪开始时间`。
- 页面时钟和烹饪计时使用同一 tick，每秒最多推进 1 秒。
- 总烹饪时长由烹饪程序中烹饪时长配置决定  
  统计规则：
- `生产总数：工单总数-已作废的数量`
- `已完成：``工单状态为出餐完成、取餐中、取餐完成的数量`
- `未完成：``生产总数-已完成的数量`
- `投料区： 待摆盆、摆盆中、摆盆完成`

温度规则：

- `同步实际设备温度`

### 7.5 出餐记录

- 出餐记录展示出口、菜品、数量、重量
- 出餐记录需要和今日菜单统计、生产流程、生产进度保持联动一致。

### 7.6 明厨亮灶

- 接入后厨摄像头实时视频，如果后台配置了多个画面，需要按网格多屏平铺或者轮播。

### 7.7 营养健康

- 左侧展示《中国居民平衡膳食宝塔（2022）》及每日推荐摄入量。
- 右侧上方展示当前选中餐品：餐品名、餐段、能量、蛋白质、脂肪、碳水化合物。支持轮播开启和暂停。
- 营养值统一标注“每 100g”，保留 1 位小数或整数的原始精度。
- 今日菜单展示生产烹饪中的菜品，每道使用一张餐品图片。
- 点击餐品图片或餐品卡片后，当前选中餐品、营养分析卡片和营养分析列表高亮同步更新。
- 营养分析数据来源用大模型计算。
- 计算规则：

原料熟重 = 原料生重 × 该原料出成率

成品总重量 = 所有原料的熟重相加求和

菜品总营养素 = 所有原料的营养素总量相加求和（单个原料取中国食物成分表，如果没有让 ai 检索）

成品每 100g 营养素 =（菜品总营养素 ÷ 成品总重量）× 100

### 7.8 出餐统计

- 支持按餐段、批次和日期筛选。
- 顶部显示计划、已完成及时、已完成延迟、未完成的工单汇总以及临时加菜的数量。
- 筛选变化后，卡片、趋势和任务明细同步刷新。
- 明细表是汇总数字的解释来源，按餐段+批次进行分组。标记批次时间、实际出餐时间、与计划的差异；细项展示分组中每个菜品的实际出餐明细，包括备餐提醒的时间、实际出餐时间、是否准时的判断以及完成情况的进度图例（绿色，已完成且按时；黄色，已完成，但延迟；粉色，未完成，存在数量缺口）
- 临时加菜作为独立明细区块展示，不归入餐段或批次；行布局与正常菜品一致，按“菜品与实际出餐时间 / 绿色数量条 / 数量尾列”对齐。仅展示菜品、出餐数量和实际出餐时间，不展示备餐提醒时间或加菜原因，不参与准时、延迟或未完成判断。
- 出餐情况占比：展示已完成及时、已完成延迟、未完成三种情况的圆环统计图。
- 各批次出餐偏差（分钟）：折线统计图，颜色按原型。对本食堂所有批次进行比较。出餐时间晚于批次时间都批次为超时批次，出餐时间早于批次时间都批次为提前批次，出餐时间等于批次时间都为准时批次。

### 7.9 行为监控（沿用现有页面）

本期保留现有行为监控页面展示，不新增行为监控功能、交互或数据字段。

### 7.10 驾驶舱配置后台修改

- 基本信息新增页面自动轮播开关与间隔、逻辑遥控器开关
- 支持营养健康页可配置餐品营养轮播间隔（默认 8 秒，范围 3–120 秒）并上传/更换膳食宝塔图片。
- 生产烹饪页可维护多条明厨亮灶视频流，每条配置画面名称与地址。
- 配置示意图作为固定背景图层；进入配置页即可直接点击文字层原位修改页面/模块名称，点击图片层选择新图并覆盖原图片。背景图层不可修改，其他页面控件不可操作
- 后台支持保存草稿、发布配置。

### 7.11 基础后台新增生产工艺营养素的查看与编辑

- 页面范围：生产工艺查看、编辑生产工艺，以及两个异常状态副本：编辑生产工艺-生成超时、编辑生产工艺-无原料。
- 营养素展示：只保留一个营养素表，统一按每 100g 成品展示能量、蛋白质、脂肪、碳水化合物、膳食纤维和钠。
- 手动维护：编辑态支持在同一张营养素表中手动输入营养值；查看态只读展示。
- AI 生成：编辑态仅提供一个“AI 生成并覆盖”按钮，生成结果回填并覆盖同一张营养素表，不新增第二份结果。
- 成功反馈：显示“生成成功，已覆盖当前营养素”。
- 超时反馈：显示“AI 生成超时，请重试”，保留当前营养素值，不覆盖原数据，并提供“重试”按钮。
- 无原料反馈：显示“当前无原料，请在当天烹饪中补充原料”，不执行生成覆盖，并提供“去当天烹饪补充原料”操作入口。
- AI 生成营养素计算与校验：

关联当天烹饪中选择的原料和调料。

将原料、调料及其配方数据喂给多个模型，分别计算成品每 100g 的营养素。

汇总多个模型的计算结果，再使用 GPT 进行交叉校验。

返回校验后的每 100g 营养素结果，并保留生成成功或异常状态提示。

## 10. 文案规范

### 10.1 面向用户的文案

- 统计字段统一使用：总产量、当前已完成、已完成重量、总重量、生产进度。
- 餐品名称使用菜单标准名称，不使用简称或营销化名称。
- 单位紧跟数值：`82.0 kg`、`26 / 33 盆`、`190 ℃`。

## 11. 非功能需求

- 首要分辨率：1920 × 1080；检查 1366 × 768 等常见窗口下的缩放和滚动。
- 首屏核心数字、当前餐段、生产状态和导航必须可读。
- 页面刷新、路由切换和组件重渲染不能导致计时加速、数据倒退或动画卡片错位。
- 菜品图片来源于后台。
- 所有列表、汇总和趋势使用同一份筛选条件及数据源。

## 12. 验收标准

### 12.1 产品验收

- [ ] 后台可多选四个系统页面；大屏导航仅显示已选页面，保持系统顺序，并显示各页面配置后的名称。
