# 智能体页面流程图

> 基于当前原型页面与实际点击交互整理。

```mermaid
flowchart LR
    subgraph menuFlow[菜单业务]
        direction TB
        menuEntry([每周菜单])
        voiceMenu[语音生成菜单]
        viewMenu[已有菜单内容]
        menuEntry -->|唤醒 / 添加| voiceMenu
        menuEntry -->|已有菜单| viewMenu
        voiceMenu -->|点击“查看菜单”| menuEntry
    end

    subgraph scheduleFlow[排产业务]
        direction TB
        scheduleEntry([智能排产])
        voiceSchedule[语音排产]
        confirmPlan{{排产计划确认}}
        confirmDetail[批次与餐品明细]
        edit[编辑排产计划]
        saved([排产计划已保存])
        scheduleEntry -->|唤醒| voiceSchedule
        voiceSchedule -->|点击预生成计划对话| confirmPlan
        confirmPlan -->|查看明细| confirmDetail
        confirmPlan -->|提交| scheduleEntry
        confirmPlan -->|暂存| saved
        scheduleEntry -->|编辑| edit
        edit -->|智能排产| confirmDetail
    end

    subgraph purchaseFlow[采购业务]
        direction TB
        purchaseEntry([订货采购])
        list[采购清单]
        quantityAdjust[调整数量 / 更新需订量]
        confirmOrder[确认下单]
        success([下单成功])
        purchaseEntry -->|去采购| list
        list -->|调整| quantityAdjust
        list -->|去结算| confirmOrder
        confirmOrder -->|确认下单| success
    end

    subgraph crossFlow[跨业务跳转]
        direction LR
        crossNav[顶部导航]
        crossMenu[每周菜单]
        crossVoice[语音排产]
        crossSchedule[智能排产]
        crossPurchase[订货采购]
        crossMenu -.->|去排产| crossSchedule
        crossVoice -.->|前往查看排产计划| crossSchedule
        crossNav -.-> crossMenu
        crossNav -.-> crossSchedule
        crossNav -.-> crossPurchase
    end

    classDef entry fill:#173379,stroke:#173379,color:#ffffff,stroke-width:2px;
    classDef page fill:#eef4ff,stroke:#7897e8,color:#173379,stroke-width:1.5px;
    classDef action fill:#ffffff,stroke:#b8c7e8,color:#334a80,stroke-width:1.5px;
    classDef dialog fill:#fff6e5,stroke:#e2a33a,color:#815519,stroke-width:2px;
    classDef state fill:#eaf8f2,stroke:#48ad86,color:#176346,stroke-width:1.5px;
    classDef cross fill:#f2efff,stroke:#8b79dc,color:#51448c,stroke-width:1.5px;
    class menuEntry,scheduleEntry,purchaseEntry entry;
    class voiceMenu,viewMenu,voiceSchedule,confirmDetail,edit,list,confirmOrder page;
    class quantityAdjust action;
    class confirmPlan dialog;
    class saved,success state;
    class crossNav,crossMenu,crossVoice,crossSchedule,crossPurchase cross;
    linkStyle default stroke:#8194b5,stroke-width:1.4px;
```

## 关键交互说明

- 每周菜单页面：每周菜单生成完成后，点击“查看菜单”返回每周菜单页面；已有菜单入口进入对应的菜单内容。
- 语音排产页面：点击“已预生成排产计划，请查看确认”才弹出“排产计划确认”；点击“前往查看排产计划”直接进入“智能排产”。
- 排产确认页：可查看/收起批次明细，可选择覆盖或保留已有计划，暂存后进入已保存状态，提交后进入智能排产。
- 采购流程：订货采购 → 采购清单 → 确认下单 → 下单成功；采购清单和确认下单均支持返回上一步修改。
- 页面辅助跳转：顶部导航可在菜单、排产、采购三个业务主页面之间直接切换；每周菜单中的“去排产”进入智能排产；排产确认中的“前往查看排产计划”进入智能排产。
