## 修复：原型预览 dev 模式 `preload-helper.js` 资源 404

- 现象：dev 预览 `http://localhost:51720/prototypes/untitled-2?agentToolbar=host` 报 `resource-load` 错误：
  `http://localhost:51720/assets/chunks/preload-helper.js` 加载失败（404）。
- 根因：dev 模式下 Vite dev server（原型，:51720）与 Axhub Make admin（:53817）是**分源**的。
  `clientPreviewPlugin` 把 admin 的 `dev-template-bootstrap.js` 跨源 import 进原型 iframe；该 bundle
  用 Vite 的 `__vitePreload`（`preload-helper.js`），对懒加载 chunk 往 `document.head` 注入
  `<link rel="modulepreload" href="/assets/chunks/...">`（根绝对路径）。因为 link 在 51720 的 iframe
  文档里，路径解析到 51720，而 dev server 不提供 `/assets/` → 404。生产环境同源故不可见，仅 dev 复现。
- 修复：新增 `vite-plugins/adminAssetProxyPlugin.ts`，serve 模式下把 dev server 上的 `/assets/`、`/runtime/`
  请求代理到 admin origin（读 `~/.axhub/make/.admin-server-info.json`，回退 53817，带健康检查和 10s 缓存）。
  已在 `vite.config.ts` 注册。重启 dev 后所有 admin chunk 均 200，原型页面与本地资源不受影响。
- 注意：改 vite.config 需重启 dev server；用户浏览器若有 404 缓存需刷新预览。
